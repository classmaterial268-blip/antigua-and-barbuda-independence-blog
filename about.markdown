# About This Blog

Our Independence is a blog dedicated
to the history, culture and heritage
of Antigua and Barbuda.

The purpose of this website is to
explore the nation's journey to
independence, recognize its cultural
celebrations and explain the importance
of national identity.

This website was created using
Jekyll, Markdown, HTML and CSS.
